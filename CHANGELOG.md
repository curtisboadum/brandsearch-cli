# Changelog

## 0.1.0 - 2026-05-29

Initial public release.

- Add JSON-first Brandsearch CLI.
- Add health, account, usage, facets, lookup, discovery dry-run, and scout-plan commands.
- Add secret-in-argument rejection.
- Add metered discovery approval gate.
- Add JSON/CSV output support for discovery.
- Add tests and GitHub Actions.
- Add optional Hermes pre-LLM hook.
- Add public documentation, security policy, contribution guide, and MIT license.
