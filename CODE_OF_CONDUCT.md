# Code of Conduct

## Our pledge

We aim to make this project useful, safe, and welcoming for people building ecommerce research and agent workflows.

## Expected behavior

- Be respectful and constructive.
- Keep discussions focused on improving the tool.
- Do not post secrets, API keys, private exports, or proprietary customer/prospect data.
- Assume good intent, but prioritize user safety and quota protection.

## Unacceptable behavior

- Harassment or discriminatory language.
- Publishing someone else's secrets or private data.
- Encouraging quota abuse or bypassing API terms.
- Spam or unrelated promotion.

## Enforcement

Maintainers may remove comments, close issues, or block contributors who violate this code of conduct.
